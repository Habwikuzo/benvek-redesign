# Images

No photographs are used yet. The site uses inline SVG illustrations (hero, solution page) as placeholders, so nothing can break.

To add real photos: save approved Benvek images here (JPG/WebP, under 300 KB each) and replace the `<svg class="flow"...>` blocks in `index.html` and `solution-detail.html` with `<img src="assets/images/NAME.jpg" alt="describe the photo" width="..." height="...">`.

Only use images Benvek owns or has licence to use. Do not use other companies' project photos.
